# 合成厦门大学

一个可直接在浏览器中游玩的校徽合成小游戏，支持电脑鼠标与手机触屏。

## 操作

- 鼠标移动选择落点，点击投放。
- 手机按住拖动瞄准，松手投放。
- 空格键投放，R 键重新开始。
- 两个相同校徽相撞会合成更大的校徽。

## 本版手感

- 球体碰撞回弹更明显，合成冲击波也稍有增强。
- 爆炸冲击随距离平缓衰减，并按球体质量分配推力：轻球飞得更远，重球更难推动。
- 不限制整体速度，垂直方向按重力自然加速下落。
- 只有已经接触堆叠、基本稳定且持续越过警戒线 2.4 秒才会失败；弹跳或快速经过警戒线不会直接判负。

## 本地运行

这是无构建步骤的静态站点。在项目目录启动任意静态服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## GitHub Pages

仓库已包含 `.github/workflows/pages.yml`。推送到 `main` 分支后，在仓库的 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**，工作流会自动部署。

## 文件

- `index.html`：页面结构
- `styles.css`：界面样式
- `game.js`：游戏、绘制、音效与物理逻辑

最高分仅保存在当前浏览器中，不会跨设备同步；清除浏览器数据会清空记录。
